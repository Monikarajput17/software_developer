# MONIKA.DEV Website

Premium multi-page React website for MONIKA.DEV.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lead Capture

The contact form posts to:

```env
VITE_LEAD_WEBHOOK_URL
```

Use `LEAD_SETUP.md` and `google-apps-script/lead-capture.gs` to connect submissions to both Google Sheets and email notifications.
